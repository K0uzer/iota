# Константы iota и размеры данных

Константы KB, MB, GB, TB и заготовка FormatSize. FormatSize не возвращает значение, поэтому программа не собирается. Примеры сезонов и битовых флагов закомментированы.

Учебная папка `basics/iota`. Код сохранён в исходном состоянии.

## Структура

- `.gitignore`
- `go.mod`
- `main.go`

## Требования и команды

Проверено на Windows с Go 1.27.1 (windows/amd64); `go.mod` требует Go 1.27.1. Команды выполняются из корня репозитория.

Точка входа: `main.go`.

```sh
go run .
```

```sh
go test ./...
go vet ./...
```
